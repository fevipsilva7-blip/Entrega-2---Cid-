Dicionário de Dados

Modelo lógico — BRMW

Sobre este documento

Este dicionário apresenta as entidades, os atributos, os tipos de dados e as chaves identificados no diagrama lógico. PK indica chave primária e FK indica chave estrangeira. Atributos marcados como PK / FK exercem as duas funções.

PK · Chave primáriaFK · Chave estrangeiraPK/FK · Chave primária e estrangeira

3 atributos
AtributoTipoChaveDescrição
id_fornecedorINTPKIdentificador único do fornecedor.
nome_empresaVARCHAR—Nome da empresa fornecedora.
contatoVARCHAR—Informação de contato do fornecedor.
